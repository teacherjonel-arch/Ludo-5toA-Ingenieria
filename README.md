# Ludo Matemático — 5.º A Ingeniería

Juego de Ludo educativo en línea para 2, 3 o 4 equipos.

## Preguntas
- Álgebra: 6 problemas.
- Aritmética: 6 problemas.
- Geometría: 6 problemas.
- Trigonometría: 6 problemas.
- Habilidad Matemática: 4 problemas.

En las casillas de preguntas se selecciona un problema al azar. Los problemas editados por los alumnos se conservan en `data/questions.json` y también quedan integrados en `public/index.html`.

## Ejecutar
```bash
npm install
npm start
```
